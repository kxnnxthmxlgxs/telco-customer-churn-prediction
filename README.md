# Telco Customer Churn Prediction

## 📊 Project Overview
This project aims to predict customer churn for a telecommunications company using machine learning. The goal is to identify customers who are likely to leave the service, allowing the company to take proactive retention measures.

## 🎯 Business Problem
Customer churn is a critical business metric for subscription-based services. Reducing churn by even a small percentage can significantly impact revenue. This project helps identify at-risk customers through predictive modeling.
